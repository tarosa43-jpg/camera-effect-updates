# Filteria

Filteria は、Webカメラ映像にエフェクトを加え、Discord・Zoom・OBSなどで使える仮想カメラとして出力する Windows 用アプリです。

**OBSは不要です。** 同梱の `CameraEffect Virtual Camera` を使うと、Filteria の映像を他のアプリのカメラとして選べます。

## ダウンロード

[最新バージョンをダウンロード](../../releases/latest)

Releases ページから **`CameraEffect-Setup.exe`** をダウンロードしてください。

## 主な機能

- 複数のカメラエフェクトを同時に重ねて使える
- PNG / JPG / WEBP / BMP / GIF を顔へ追従表示できる。GIFもアニメーションのまま再生
- AIで人物だけを切り抜き、グリーンバックなしで背景画像を差し替え
- AI背景は **高精度（MODNet / GPU優先）** と **軽量（MediaPipe / CPU）** を選べる
- AIマスク品質を 1〜3 で調整できる
- リアルタイムFPS表示を必要な時だけオンにできる
- 美肌、モザイク、ドット絵、グリッチ、漫画調、VHS、雨、音で波紋などのエフェクト
- カメラのズーム、明るさ、コントラスト、彩度を調整できる
- ライト / ダークモード、プリセット、ショートカット、設定の書き出し・読み込みに対応

## インストール

### 必要なもの

- Windows 10 または Windows 11（64bit）
- Webカメラ
- 初回セットアップ時だけインターネット接続

### 手順

1. [Releases](../../releases/latest) から `CameraEffect-Setup.exe` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックします。
3. セットアップ画面を進めます。最後に **「CameraEffect Virtual Camera を設定する」** が表示されたら、チェックを入れたまま完了してください。
4. Windowsの確認画面が出たら **「はい」** を押します。
5. 仮想カメラの設定用ウィンドウが開く場合は、`SUCCESS` と出るまで閉じずに待ちます。
6. Filteria を起動します。入力にはWebカメラ本体を選び、`CameraEffect Virtual Camera` はDiscordなどの出力先で選びます。

> 初めて配布される EXE では Windows Defender / SmartScreen が確認画面を出すことがあります。配布元が信頼できることを確認したうえで実行してください。

## Discord・Zoomで使う

Filteria を起動したまま、通話アプリのカメラを次のように変更します。

| アプリ | 選ぶカメラ |
| --- | --- |
| Discord | ユーザー設定 → 音声・ビデオ → カメラ → `CameraEffect Virtual Camera` |
| Zoom | ビデオ設定 → カメラ → `CameraEffect Virtual Camera` |
| OBS | 映像キャプチャデバイスを追加 → `CameraEffect Virtual Camera` |

## 基本の使い方

### エフェクト

左側のエフェクトタイルを押すとオン・オフを切り替えられます。複数を同時に選べます。元に戻したい時は **「通常映像に戻す」** を押してください。

### 顔追従画像

1. 右側の **「画像を選ぶ」** から画像またはGIFを選びます。
2. **「顔追従画像」** をオンにします。
3. 調整欄の大きさ・横位置・縦位置で見た目を整えます。

背景を透明にしたい場合は透過PNGまたは透過GIFを使ってください。

### AI背景（グリーンバック不要）

1. 上部の **［設定］→［AI背景画像を選ぶ］** を押します。
2. 背景にしたい PNG / JPG / WEBP / BMP を選びます。
3. **「AI背景（自動切り抜き）」** をオンにします。

上部の **［設定］→［AI切り抜き］** から、使い方に合う方式を選べます。

| 方式 | 向いている場面 | GPU |
| --- | --- | --- |
| 高精度（MODNet / GPU優先） | 髪や輪郭を優先したい、RTXなどのGPUがあるPC | WindowsのDirectMLでGPUを優先使用。GPUが使えないPCはCPUへ自動切替。 |
| 軽量（MediaPipe / CPU） | ゲームと同時に使いたい、負荷を抑えたい | Windows版ではCPU処理。RTXは使用しません。 |

調整欄を下へスクロールすると **「AIマスク品質」** を変更できます。

- `1`：軽さ優先
- `2`：標準
- `3`：髪や輪郭を優先。高精度方式では負荷が上がります

「AI背景」と「グリーンバック」は同時には使えません。緑背景を用意できる場合はグリーンバックのほうが軽く、境目も安定します。

## FPS表示と軽量化

プレビューはゲーム中など不要な時に **「プレビューをオフ」** にすると少し軽くなります。

処理速度を確認したい時は、上部の **［表示］→［リアルタイムFPSを表示］** をオンにしてください。プレビュー上部に現在のFPSが表示されます。同じ項目でオフに戻せます。

「動作の軽さ」は次を目安に選んでください。

| モード | 解像度 / FPS | おすすめの場面 |
| --- | --- | --- |
| 標準 | 720p / 30FPS | 普段使い・高精度AI背景 |
| 軽量 | 540p / 24FPS | ゲームと同時に使う時 |
| 最軽量 | 360p / 20FPS | CPU負荷を最優先で下げたい時 |

## 困ったとき

### 仮想カメラがDiscordなどに出ない

1. Discord / Zoom / OBS を完全に終了します。
2. Filteria を閉じます。
3. インストール先の `install_virtual_camera.bat` を実行します。通常の場所：

   `%LOCALAPPDATA%\Programs\Filteria\install_virtual_camera.bat`

4. Windowsの確認画面では「はい」を選び、処理完了後に通話アプリを開き直します。

### カメラが開けない・映らない

- Discord、Zoom、OBS、ブラウザなど、物理カメラを使っているアプリを閉じてからFilteriaを起動してください。
- カメラ一覧で「再検索」を押し、正しいWebカメラを選び直してください。
- 問題が続く場合は、アプリの **［設定］→［診断］** を開き、表示内容と `CameraEffect-debug.log` を添えて報告してください。

## プライバシー

映像処理はすべてPC上で行われます。MODNet・MediaPipeによるAI背景の切り抜きもPC内で処理し、カメラ映像を外部サーバーへ送信しません。更新確認や仮想カメラの初回セットアップ時のみ、インターネット接続を使用します。
