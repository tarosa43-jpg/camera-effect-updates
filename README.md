# Filteria

Filteria は、Webカメラ映像へエフェクトを加え、Discord・Zoom・OBSなどで使える仮想カメラとして出力する Windows 用アプリです。

**OBSは不要です。** 同梱の `CameraEffect Virtual Camera` を使うと、Filteria の映像を他のアプリのカメラとして選べます。

## ダウンロード

[最新バージョンをダウンロード](../../releases/latest)

Releases ページから **`CameraEffect-Setup.exe`** をダウンロードしてください。

## できること

- エフェクトを複数同時に重ねて使える
- 好きな PNG / JPG / WEBP / BMP /GIFを顔へ追従表示できる
- 顔追従は YuNet 顔検出とフレーム追跡を組み合わせ、横顔や速い動きにも対応
- カメラのズーム、明るさ、コントラスト、彩度を調整できる
- 音量に反応して映像が波紋のように揺れる「音で波紋」エフェクト
- カメラ比率を 16:9 / 4:3 / 1:1 / 9:16 へ変更できる
- ライトモード / ダークモード、プリセット、ショートカット設定に対応
- 低負荷モードとプレビューのオン・オフで、ゲーム中でも使いやすい

## インストール

### 必要なもの

- Windows 10 または Windows 11（64bit）
- Webカメラ
- 初回セットアップ時だけインターネット接続

### 手順

1. [Releases](../../releases/latest) から `CameraEffect-Setup.exe` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックします。
3. セットアップ画面を進めます。最後に **「CameraEffect Virtual Camera を設定する」** が表示されたら、チェックを入れたまま完了してください。
4. Windows の確認画面が出たら **「はい」** を押します。
5. 仮想カメラの設定用ウィンドウが開く場合は、処理が終わるまで閉じずに待ちます。
6. `Filteria` を起動します。

> 初めて配布される EXE では、Windows Defender / SmartScreen が確認画面を出すことがあります。配布元が信頼できることを確認したうえで実行してください。

## Discord・Zoomで使う

Filteria を起動したまま、使いたい通話アプリでカメラを次のように変更します。

| アプリ | 選ぶカメラ |
| --- | --- |
| Discord | ユーザー設定 → 音声・ビデオ → カメラ → `CameraEffect Virtual Camera` |
| Zoom | ビデオ設定 → カメラ → `CameraEffect Virtual Camera` |
| OBS | 映像キャプチャデバイスを追加 → `CameraEffect Virtual Camera` |

Filteria を終了すると、仮想カメラの映像も止まります。

## 基本の使い方

### 1. カメラを選ぶ

右側の「設定」内、一番上のカメラ一覧から使いたい Web カメラを選びます。見つからないときは **「再検索」** を押してください。

### 2. エフェクトを選ぶ

左下の「エフェクト」タイルを押すとオン・オフを切り替えられます。複数選択もできます。すべて解除したいときは **「通常映像に戻す」** を押します。

| エフェクト | 内容 |
| --- | --- |
| 左右反転 | 映像を鏡のように左右反転します。 |
| モザイク | モザイク加工をかけます。 |
| ドット絵風 | 映像をピクセルアート風にします。 |
| グリッチ | 色ずれ・走査線でデジタルノイズ風にします。 |
| 美肌加工 | 肌をなめらかに見せます。 |
| シンメトリー | 顔の中央を基準に左右対称にします。 |
| 凹（ピンチ） / 凸（バルジ） | 映像を凹ませる・膨らませる変形です。 |
| 白黒 | モノクロ映像にします。 |
| サーモグラフィー | 熱画像風の色にします。 |
| X線 | X線写真風にします。 |
| 雨 | 雨が降っているような演出を加えます。 |
| 音で波紋 | マイクの音量に合わせて映像が波紋のように揺れます。 |
| VHS風 | VHSテープのようなノイズと色ずれを加えます。 |
| 顔追従画像 | 選んだ画像を顔に追従させます。 |

### 3. 顔追従画像を使う

1. 右側の「顔追従に使う画像」で **「画像を選ぶ」** を押します。
2. PNG / JPG / WEBP / BMP の画像を選びます。
3. 「顔追従画像」タイルをオンにします。
4. 「追従画像の大きさ」「横位置」「縦位置」で位置を調整します。

背景を透明にしたいときは、**透過 PNG** を使ってください。顔が暗すぎる、極端な横顔、顔が小さすぎる場面では追従が弱くなることがあります。

### 4. 調整する

右下の「調整」はスクロールできます。主な項目は次の通りです。

- カメラのズーム
- 明るさ / コントラスト / 彩度
- モザイク、ドット絵、グリッチ、美肌、凹・凸の強さ
- 雨の強さと雨粒の大きさ
- 追従画像の大きさ・位置
- マイク感度

値を最初の状態へ戻すには **「調整をすべてリセット」** を押します。画像、プリセット、ショートカット設定は消えません。

### 5. 音で波紋を使う

1. 右側のマイク一覧から使いたいマイクを選びます。
2. 「音で波紋」をオンにします。
3. 「マイク感度」と「波紋の強さ」を調整します。

マイクの音を大きく拾うほど、映像の波紋も強くなります。

## プレビューと軽量化

アプリ内の「カメラ プレビュー」は、最終的に出力される映像を確認するためのものです。ゲーム中など、PCを軽くしたいときは **「プレビューをオフ」** にしてください。

「動作の軽さ」は次を目安に選んでください。

| モード | 解像度 / FPS | おすすめの場面 |
| --- | --- | --- |
| 標準 | 720p / 30FPS | 普段使い |
| 軽量 | 540p / 24FPS | ゲームと同時に使うとき |
| 最軽量 | 360p / 20FPS | CPU負荷を最優先で下げたいとき |

美肌・凹凸・顔追従など、重いエフェクトを同時に多く選ぶほどCPU使用率は上がります。

## 出力サイズとプリセット

### 出力の縦横比

「出力の縦横比」から、カメラのまま / 16:9 / 4:3 / 1:1 / 9:16 を選べます。映像は比率に合わせて**引き伸ばさず、中央を切り抜いて**出力します。

### プリセット

エフェクト・調整値・出力設定をまとめて保存できます。

1. 好きな見た目に設定します。
2. 右上の **「プリセット保存」** を押します。
3. 次回から右上の一覧で選ぶだけで呼び出せます。

不要なプリセットは、右上の一覧で選択してから**右クリック**すると削除できます。

## ショートカットキー

右下の **「ショートカット設定」** から、各エフェクトのキーを自由に変更できます。空欄にすると、そのエフェクトのショートカットを無効にできます。

初期状態では、たとえば `Ctrl + Alt + 1` がモザイク、`Ctrl + Alt + 4` が顔追従画像、`Ctrl + Alt + 0` がすべて解除です。

## アップデート

右上の **「更新を確認」** を押すと、新しいバージョンがあるか確認できます。更新が見つかった場合は、画面の案内に従ってダウンロード・インストールしてください。

## 困ったとき

### `CameraEffect Virtual Camera` がDiscordなどに出ない

1. Discord / Zoom / OBS を完全に終了します。
2. Filteria を閉じます。
3. インストール先の `install_virtual_camera.bat` をダブルクリックします。通常の場所は次です。

   ```text
   %LOCALAPPDATA%\Programs\Filteria\install_virtual_camera.bat
   ```

4. Windows の確認画面では「はい」を選び、処理完了後に通話アプリを開き直します。

### カメラが開けない・映らない

- Discord、Zoom、OBS、ブラウザなど、物理カメラを使っているアプリをいったん閉じてから Filteria を起動してください。
- Filteria のカメラ一覧で「再検索」を押し、正しいカメラを選び直してください。
- USBカメラは一度抜き差しすると直る場合があります。

### 起動直後に閉じる・エラーになる

一度起動したあと、インストール先に作成される `CameraEffect-debug.log` を確認してください。問題を報告するときは、このログと状況が分かるスクリーンショットを添えてください。

### 顔追従が安定しない

- 顔全体に明るい光が当たる場所で使ってください。
- 顔が小さすぎる、強い逆光、極端な横顔では検出できないことがあります。
- 追従画像が大きく急に変わる場合は、「追従画像の大きさ」を少し下げてみてください。

## アンインストール

Filteria は Windows の「インストールされているアプリ」から削除できます。仮想カメラだけを削除したい場合は、インストール先にある `uninstall_virtual_camera.bat` を実行してください。

## プライバシー

映像処理はPC上で行われます。Filteria はカメラ映像を外部サーバーへ送信しません。更新確認や仮想カメラの初回セットアップ時のみ、インターネット接続を使用します。
