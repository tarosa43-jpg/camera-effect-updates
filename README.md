# Filteria

⚠ このアプリは AI を使用して制作しています。

Filteria は、Webカメラ映像にエフェクトを加え、Discord・Zoom・OBSなどで使える仮想カメラとして出力する Windows 用アプリです。

**OBSは不要です。** 同梱の `CameraEffect Virtual Camera` を使うと、Filteria の映像を他のアプリのカメラとして選べます。

## ダウンロード

[最新バージョンをダウンロード](../../releases/latest)

Releases ページから **`CameraEffect-Setup.exe`** をダウンロードしてください。

## 主な機能

- エフェクトを複数同時に重ねて使える
- PNG / JPG / WEBP / BMP / GIF を顔に追従表示できる（GIFもアニメーションのまま再生）
- AIで人物だけを切り抜き、グリーンバックなしで背景画像へ差し替え
- AI背景は **高精度（MODNet / GPU優先）** と **軽量（MediaPipe / CPU）** を選べる
- AIマスク品質を 1〜3 で調整できる
- リアルタイムFPS表示を必要な時だけオンにできる
- 美肌、モザイク、ドット絵、グリッチ、漫画調、VHS、雨、音で波紋などのエフェクト
- カメラのズーム、明るさ、コントラスト、彩度を調整できる
- ライト / ダークモード、プリセット、ショートカット、設定の書き出し・読み込みに対応

## インストール

### 必要なもの

- Windows 10 または Windows 11（64bit）
- Webカメラ
- 初回セットアップ時だけインターネット接続

### 手順

1. [Releases](../../releases/latest) から `CameraEffect-Setup.exe` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックして、セットアップを進めます。
3. 最後に **CameraEffect Virtual Camera を設定する** が表示されたら、チェックを入れたまま完了します。
4. Windows の確認画面が出たら **はい** を押します。設定用ウィンドウは `SUCCESS` と出るまで閉じずに待ちます。
5. Filteria を起動します。入力にはWebカメラ本体を選びます。

> 初めて配布される EXE では Windows Defender / SmartScreen が確認画面を出すことがあります。配布元が信頼できることを確認してから実行してください。

## Discord・Zoomで使う

Filteria を起動したまま、通話アプリのカメラに **`CameraEffect Virtual Camera`** を選びます。

| アプリ | 選ぶカメラ |
| --- | --- |
| Discord | ユーザー設定 → 音声・ビデオ → カメラ → `CameraEffect Virtual Camera` |
| Zoom | ビデオ設定 → カメラ → `CameraEffect Virtual Camera` |
| OBS | 映像キャプチャデバイス → `CameraEffect Virtual Camera` |

Filteria を終了すると、仮想カメラの映像も止まります。

## 基本の使い方

### カメラ・エフェクト

右側の設定から使う Webカメラを選びます。左側のエフェクトタイルを押すとオン・オフを切り替えられ、複数を重ねられます。すべて解除したい時は **通常映像に戻す** を押します。

### 顔追従画像

1. 右側の 顔追従に使う画像 で **画像を選ぶ** を押します。
2. 画像を選んだ後、顔追従画像 のタイルをオンにします。
3. 追従画像の大きさ・横位置・縦位置で見た目を調整します。

背景を透明にしたい場合は、透過 PNG または透過 GIF を使ってください。

### AI背景（グリーンバック不要）

1. 上部の **設定 → AI背景画像を選ぶ（グリーンバック不要）** を押します。
2. 背景にしたい画像を選びます。
3. AI背景（自動切り抜き）が自動でオンになります。

上部の **設定 → AI切り抜き** から、切り抜き方式を選べます。

| 方式 | 向いている場面 | GPU |
| --- | --- | --- |
| 高精度（MODNet / GPU優先） | 髪や輪郭を優先したい、RTXなどのGPUがあるPC | DirectMLでGPUを優先使用。使えないPCはCPUへ自動切替。 |
| 軽量（MediaPipe / CPU） | ゲームと同時に使いたい、CPU負荷を抑えたい | Windows版ではCPU処理。RTXは使用しません。 |

右側の調整を下へスクロールすると **AIマスク品質** を変更できます。`1` は軽さ優先、`2` は標準、`3` は髪や輪郭を優先します。

### 軽量化とFPS表示

ゲーム中などPCを軽くしたい時は **プレビューをオフ** にしてください。上部の **表示 → リアルタイムFPSを表示** をオンにすると、プレビュー上部で現在の出力FPSを確認できます。

AI背景が重い場合は、軽量（MediaPipe / CPU）・低いAIマスク品質・プレビューオフを組み合わせてください。

## 困ったとき

### CameraEffect Virtual Camera が出ない

1. Discord / Zoom / OBS を完全に終了します。
2. Filteria を閉じます。
3. インストール先の `install_virtual_camera.bat` をダブルクリックします。通常は `%LOCALAPPDATA%\Programs\Filteria\install_virtual_camera.bat` にあります。
4. Windowsの確認で はい を押し、完了後に通話アプリを開き直します。

### カメラが開けない・映らない

- Discord、Zoom、OBS、ブラウザなど、物理カメラを使っているアプリを閉じてから Filteria を起動してください。
- カメラ一覧で 再検索 を押し、正しいカメラを選び直してください。
- うまくいかない時は上部の **設定 → 診断** を開き、診断内容をコピーして共有してください。

## プライバシー

映像処理はPC上で行われます。AI背景の切り抜きもMODNetまたはMediaPipeの同梱モデルでPC内だけで処理します。Filteria はカメラ映像を外部サーバーへ送信しません。
